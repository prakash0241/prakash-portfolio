# Prakash — Java Full Stack Developer Portfolio

Interactive single-page developer portfolio featuring a scroll-scrubbed cinematic background video, animated career metrics, and a built-in Firebase Cloud CMS admin dashboard.

## ✨ Key Features
- **Cinematic Scroll-Scrubbed Hero:** Interactive background video synced to page scroll and pointer movement.
- **Authenticated Cloud CMS (`#admin`):** Built-in admin dashboard secured with Firebase Authentication (`sprakash0241@gmail.com`) and Cloud Firestore for live content updates without redeploying code.
- **Dynamic Content Management:** Live CRUD controls for Projects, Skills, Education/Experience timeline, Certifications, LeetCode problem counter, and Resume PDF publishing.
- **Responsive Dark-Mode UI:** Glassmorphic cards, mobile navigation drawer, one-click email/phone copy buttons, and reduced-motion accessibility support.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Custom Properties, Grid/Flexbox, Glassmorphism), Vanilla JavaScript (ES6+ Modules)
- **Backend & Cloud:** Firebase Authentication, Cloud Firestore
- **Typography:** Anton, Plus Jakarta Sans, DM Mono
